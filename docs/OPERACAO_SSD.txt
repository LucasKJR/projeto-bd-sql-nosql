LABORATÓRIO BD — AMBIENTE LOCAL

Confira o contexto Docker antes de iniciar, parar ou recarregar os serviços.
A configuração do SSD usada no laboratório original é local e não acompanha o repositório.
Em outro computador, siga a instalação e geração do README.md.

Para iniciar os contêineres existentes e abrir o dashboard:
docker compose up -d --wait
python -m lab serve --port 8765

Abra http://127.0.0.1:8765/ no próprio computador. Os serviços usam portas de
localhost; não exponha o laboratório à rede pública.

Se os bancos já contiverem a massa, não recarregue. Para encerrar, pare o
servidor Python com Ctrl+C e, no mesmo contexto Docker, execute
docker compose stop. Não use down -v nem exclua os volumes ou a VM.
