LABORATÓRIO BD — SSD
Código, massa, ambiente Python, caches, temporários configuráveis e discos da VM Colima isolada ficam nesta pasta. O Lima ainda cria pequenos sockets temporários de controle em /tmp do macOS; dados, imagens e volumes ficam no SSD.
O Docker/Colima já existente não foi movido nem substituído.

Antes de usar comandos no Terminal:
source '/Volumes/Estacao trabalho/BDLab/ssd-env.sh'
cd "$BDLAB/project/Projeto_BD_SQL_NoSQL"

Iniciar VM isolada existente:
colima start --activate=false
Iniciar bancos:
docker-compose -p bdlab-ssd up -d --wait
Dashboard:
.venv/bin/python -m lab serve --port 8765

ANTES DE DESCONECTAR O SSD:
Pare o servidor Python com Ctrl+C. Na mesma sessão com ssd-env.sh carregado:
docker-compose -p bdlab-ssd stop
colima stop
Não use down -v nem delete: essas opções removem os bancos.
Não execute comandos de interrupção sem carregar ssd-env.sh, para não atingir o ambiente Colima antigo.
